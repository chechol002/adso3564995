01-Emmet

Plugin para codificación más rápida en HTML y CSS.

01-Child >

Create child elements (nesting).

Example:

ul>li>a↔️

Result:

<ul> <li> <a href=""></a> </li> </ul>

02-Sibling +

Create sibling elements.

Example:

header+section+footer↔️

Result:

<header></header> <section></section> <footer></footer>

03-Multiplication *

Repeat elements multiple times.

Example:

ul>li*3↔️

Result:

<ul> <li></li> <li></li> <li></li> </ul>

04-Class .

Create a class atribute

Example:

div.important↔️

.danger↔️

Result:

<div class="important"></div> <div class="danger"></div>

05-Classes ...

Create multiples classes atributes

Example:

div.red.green.blue

Result:

<div class="red green blue"></div>

06-Identification or ID #

Create an ID atribute

Example:

menu#cod123

Result:

<menu id="cod123"></menu>

07-Text {}

Insert text content

Example:

p{lorem ipsum dolor}

a{Click here}

Result:

<p>lorem ipsum dolor</p> <a href="">Click here</a>

08-Custom attributes []

Create a custom attribute

Example:

input[type=number]

Result:

<input type="number">

09-Item numbering $

Adds consecutive numbers

Example:

ul>li.option$*3

Result:

<ul> <li class="option1"></li> <li class="option2"></li> <li class="option3"></li> </ul>

10-Reverse Numbering @-

Inverts numbering order.

Example:

ul>li.option$@-*3

Result:

<ul> <li class="option3"></li> <li class="option2"></li> <li class="option1"></li></ul>

11-Base Numbering @n

Defines a base number for sequences.

Example:

ul>li.num$@3*4

Result:

<ul> <li class="num3"></li> <li class="num4"></li> <li class="num5"></li> <li class="num6"></li></ul>

12-Climb Up ^

Moves up one level

Example:

section>article>div^p

Result:

<section> <article> <div></div> </article> <p></p> </section>

13-Grouping ()

Groups elements together.

Example:

div(header>nav)+(section>article)

Result:

<div> <header> <nav></nav> </header> <section> <article></article> </section> </div>

14-Lorem lorem

Generates placeholder text

Example:

lorem5

Result:

<lorem> ipsum dolor sit amet

15-HTML !

Creates various HTML document types

Example:

html:5

html:xs

html:xt

html:4s

html:4t

Result:

<html:4s></html:4s> <html:xs></html:xs> <html:xt></html:xt> <html:4t></html:4t>

16-Meta TAGS meta:

Generate meta tags

Example:

meta:vp

Result:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

17-Challenge 🚀

Generates emmet challenges for practice

Example:

header#header>nav.navbar-inverse>div.container>(div.navbar-header>(button[type="button"].navbar-toggle>span.sr-only{Toogle navigation}+span.icon-bar*3)+a[href="index.php"].navbar-brand>img[src="imags/logo.png"][alt="Logo"])+div.collapse>ul.nav.navbar-nav>(li>a[href="index.php"].link{Inicio})+(li.active.link>a[href="Login.html"]{Ingresar})+(li>a[href="registro.html"].link{Registrarse})+(li>a[href="contacto.html"].link{Contacto})
